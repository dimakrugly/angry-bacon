# Angry Bacon

Проєкт на чистому HTML, CSS і JavaScript — без фреймворків і збирачів.
Шматки бекону літають і відбиваються від країв екрана, як логотип DVD, а на фоні грає «Хава нагіла».

Щоб запустити, відкрийте `index.html` у браузері.

## Музика

`hava-nagila.mp3` — перекодований у MP3 файл
[Hava nagila.ogg](https://commons.wikimedia.org/wiki/File:Hava_nagila.ogg) з Wikimedia Commons
(суспільне надбання).
